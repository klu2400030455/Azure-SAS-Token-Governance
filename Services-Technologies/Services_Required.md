# Services and Technologies Required

## Azure Services

- Azure Storage Account
- Azure Blob Storage
- Shared Access Signature (SAS)
- Azure Monitor
- Log Analytics Workspace
- Diagnostic Settings

## Security Features

- SAS permission control
- SAS expiry time
- Read, Write and Delete permissions
- HTTPS-only access
- Storage access auditing

## Query and Monitoring

- Kusto Query Language (KQL)
- Azure Monitor Logs
- Log Analytics

## Project Purpose

These Azure services are used to provide controlled, time-limited access to
Blob Storage and to monitor and audit storage access activities.
